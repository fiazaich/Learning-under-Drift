This real-data experiment is an applied robustness / partial-observability check.
It is not a direct contraction-theorem test and does not estimate intrinsic C_T/T.

Channels:
- Null blind: Fixed deterministic row/hash buckets only; no predictions or task variables.
- Coarse score: Prediction-score bins only, with bin edges fixed from the baseline D_0 predictions.
- Task minus quantity: Prediction-score bins x Unit Cost bins x Sales Channel subgroup; omits Order Quantity.
- Task minus cost: Prediction-score bins x Order Quantity bins x Sales Channel subgroup; omits Unit Cost.
- Task minus subgroup: Prediction-score bins x Order Quantity bins x Unit Cost bins; omits Sales Channel subgroup.
- Task-aligned: Prediction-score bins x Order Quantity bins x Unit Cost bins x Sales Channel subgroup.
